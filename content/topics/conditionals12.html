First Conditional

We use the First Conditional to talk about real or likely situations in the future. These are possible things that might happen.

Structure: If + Present Simple, will + Verb1

If it rains, we will stay at home.

If I study hard, I will pass the exam.

She will miss the bus if she doesn't hurry.

Key points:

  • The if part is in present simple.
  • The result uses will + verb.
  • You can change the order: We will stay at home if it rains.
  • In the other clause, we can also use imperatives or can + verb1.

Second Conditional

We use the Second Conditional to talk about hypothetical situations — things that probably won't happen, or are imaginary.

Structure: If + Past Simple, would + Verb1

If I won the lottery, I would travel the world.

She would be happy if she got the job.

If I were you, I wouldn't do that.

With I / he / she / it we often use were instead of was in formal English.

If I were rich, I would buy a mansion.

The if part uses past simple, but it's not about the past — it's about unreal or imagined situations.

1st vs 2nd Conditional

ConditionIf ClauseMain ClauseExample
1stIf + present simplewill + verb1If I study, I will pass the exam.
2ndIf + past simplewould + verb1If I studied, I would pass the exam (but I don't).

Would vs Could

Would expresses result or consequence. Could expresses possibility or ability.

If I had more money, I would buy a new phone.

If I spoke Spanish, I could work in Spain.

If Clause (Past Simple)Main Clause – Using WouldMain Clause – Using Could
If I had a carI would drive to work.I could drive to the countryside.
If she knew the answerShe would tell you.She could help you with your homework.
If we had more free timeWe would travel more.We could learn a new language.
WordFunctionMeaning
WouldResult or consequenceWhat someone would do in that situation.
CouldPossibility or abilityWhat someone would be able to do.

Extra first / second conditional notes

  • First conditional can also use imperatives and modal verbs in the main clause: If you see Anna, call me. If you study, you can pass.
  • unless means if not: I won't go unless you come with me.
  • Second conditional talks about unreal present or future situations. The past form in the if-clause does not mean past time here.
  • If I were you is the standard phrase for advice.

🧑‍🏫 Ravza için detaylı anlatım

Bu konuda asıl hedef: First Conditional ile gerçek olası gelecek, Second Conditional ile hayali durum kurmak.

Conditional cümlelerde if kısmı ve sonuç kısmı birbiriyle zaman uyumu ister. First conditional gerçekçi ihtimal, second conditional hayali veya düşük ihtimal anlatır.

1. Önce anlamı yakala
If it rains, we will stay home = olabilir. If I won the lottery, I would travel = hayali.
2. Sonra yapıyı kur
First: If + Present Simple, will/can/imperative + V1. Second: If + Past Simple, would/could + V1.
3. En son kontrol et
Bu durum gerçekçi bir gelecek ihtimali mi, yoksa hayali mi?

🧩 Soru çözerken adım adım

  • If-clause içindeki zamanı bul.
  • First conditional ise if kısmında will kullanma.
  • Second conditional'da past form geçmiş anlam vermez; hayali durum kurar.
  • unless = if not anlamını unutma.

⚠️ Ravza'nın dikkat etmesi gereken hata

Tipik hata: If it will rain gibi if kısmında will kullanmak.

Doğru düşünme: First conditional if kısmı present simple alır: If it rains, I will stay.

🧑‍🏫 Profesyonel öğretmen anlatımı

First Conditional gerçek veya muhtemel gelecek durumları anlatır. If kısmında Present Simple, sonuç kısmında will + verb1 kullanılır. Kaynak ayrıca can, imperatives ve other modals kullanımını da verir. Second Conditional ise hayali veya gerçek dışı durumları anlatır; if kısmında Past Simple, sonuçta would + verb1 kullanılır.

  • 📌 First Conditional: real/likely future.
  • 📌 If + Present Simple, will + V1.
  • 📌 First conditional result clause can, might, must, should veya imperative alabilir.
  • 📌 Second Conditional: hypothetical/unreal present or future.
  • 📌 If I were you tavsiye kalıbında were kullanılır.

✅ Kaynak örnekleriyle anlatım

English: If I study hard, I will pass the exam.

Türkçe: Çok çalışırsam sınavı geçeceğim.

Öğretmen notu: Olası gelecek sonucu; first conditional.

English: If I had more money, I would buy a new phone.

Türkçe: Daha çok param olsaydı yeni telefon alırdım.

Öğretmen notu: Hayali durum; second conditional.

English: I won't go unless you go, too.

Türkçe: Sen de gitmezsen gitmem.

Öğretmen notu: Unless = if not.

⚠️ Sık yapılan hatalar

Yanlış: If it will rain, we will stay home.

Doğru: If it rains, we will stay home.

Neden? First conditional if clause içinde Present Simple kullanılır.

Yanlış: If I was you, I would...

Doğru: If I were you, I would...

Neden? Kaynakta tavsiye kalıbında only were kullanımı vurgulanır.
